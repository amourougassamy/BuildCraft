# BuildCraft 3D — Version 3 Web Edition

Play in your browser at the repository's GitHub Pages URL under `/my-version/` once Pages is enabled.

Features: orbitable 3D models, editable components, templates, six adjustable loads, educational demand/capacity score, animated exaggerated sway, JSON export/import.

Requires internet access for Three.js. Simulation is a **game approximation**, not a structural engineering analysis or code-compliant calculation.
